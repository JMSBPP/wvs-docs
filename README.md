# wvs-docs

A topic-organized CFMM research shelf: papers, notes, and exercises on options,
volatility swaps, and the mathematics behind them, tracked as text with PDFs kept
local-only.

## Layout

```
wvs-docs/
├── README.md, CLAUDE.md
├── .gitignore
├── manifest/            # sources.yaml, scan.yaml (gitignored), schema.json;
│                       cleanup-log.yaml (Phase 2, not yet present)
├── topics/<topic>/
│   ├── INDEX.md         # generated by `shelf index`
│   ├── refs/<citekey>.md
│   ├── notes/
│   └── exercises/
├── text/<citekey>.md    # extracted text
├── agents/              # skills, commands, agent notes
├── docs/superpowers/{specs,plans}/
├── shelf/               # Haskell CLI: scan, apply, extract, index, manifest check
├── index/                # gitignored BM25 index cache
└── pdfs/                 # gitignored, local-only
```

## Reading

- **Tier 1** — read the extracted text directly under `text/<citekey>.md`.
- **Tier 2** — fetch the source PDF with `shelf fetch` (Phase 2; not yet implemented).

## The `shelf` CLI

Built and shipped in Phase 1 (Haskell, `shelf/`; `stack install` from inside it):

| command | what it does |
|---|---|
| `shelf scan [--root DIR]` | Walk for PDFs, hash and group them, propose citekey/topics/year/include, and merge the proposals into `manifest/scan.yaml` without overwriting human edits. |
| `shelf apply` | For every `include: true` row: copy the PDF to `pdfs/`, extract `text/<citekey>.md`, scaffold `topics/<t>/refs/<citekey>.md`, upsert the manifest row, drop the scan row. |
| `shelf extract [CITEKEY\|--all]` | Re-run `pdftotext` for one manifest source or all of them. |
| `shelf index` | Rebuild the BM25 index in `index/` and re-render `topics/*/INDEX.md` and `topics/README.md`. |
| `shelf manifest check [--require]` | Validate `manifest/sources.yaml` against the topics on disk; `--require` also fails when the manifest or `topics/` is missing. This is the CI gate. |

## Adding sources

`shelf scan` → triage the results in `manifest/scan.yaml` → `shelf apply` to commit
them into `manifest/sources.yaml` and generate `text/` + `topics/<t>/refs/` entries.
Never hand-edit `sources.yaml` except for metadata fixes, then run
`shelf manifest check`.
