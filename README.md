# cfmm-refs

A topic-organized CFMM research shelf: papers, notes, and exercises on options,
volatility swaps, and the mathematics behind them, tracked as text with PDFs kept
local-only and mirrored to a public bucket.

## Layout

```
cfmm-refs/
├── README.md, CLAUDE.md
├── .gitignore
├── manifest/            # sources.yaml, cleanup-log.yaml, schema.json;
│                       scan.yaml (gitignored)
├── topics/<topic>/
│   ├── INDEX.md         # generated by `shelf index`
│   ├── refs/<citekey>.md
│   ├── notes/
│   └── exercises/
├── text/<citekey>.md    # extracted text
├── agents/              # skills, commands, agent notes
├── docs/superpowers/{specs,plans}/
├── shelf/               # Haskell CLI: scan, apply, extract, index, migrate,
│                       push, fetch, url, manifest check, cleanup
├── index/                # gitignored BM25 index cache
└── pdfs/                 # gitignored, local-only; rebuilt with `shelf fetch`
```

## Reading

- **Tier 1** — read the extracted text directly under `text/<citekey>.md`.
- **Tier 2** — fetch the source PDF with `shelf fetch`. A fresh clone can rebuild
  the whole of `pdfs/` with no credentials: the bucket is public-read, and each
  card's `pdf:` field is the object's URL.

## The `shelf` CLI

Haskell, in `shelf/`; `stack install --local-bin-path ~/.local/bin` from inside it.
Every command takes `--repo DIR`, which defaults to the nearest ancestor holding a
`manifest/` or `topics/`.

| command | what it does |
|---|---|
| `shelf scan [--root DIR]` | Walk for PDFs, hash and group them, propose citekey/topics/year/include, and merge the proposals into `manifest/scan.yaml` without overwriting human edits. `--root` defaults to `$HOME`. |
| `shelf apply` | For every `include: true` row: copy the PDF to `pdfs/`, extract `text/<citekey>.md`, scaffold `topics/<t>/refs/<citekey>.md`, upsert the manifest row, drop the scan row. |
| `shelf extract (--all \| CITEKEY)` | Re-run `pdftotext` for one manifest source or all of them. |
| `shelf index` | Rebuild the BM25 index in `index/`, refresh every card header, and re-render `topics/*/INDEX.md` and `topics/README.md`. |
| `shelf migrate` | Rewrite `manifest/sources.yaml` from schema 1 to schema 2. Refuses while the file has uncommitted changes, or while git cannot say whether it does. |
| `shelf push (--all \| CITEKEY) [--verify get\|head] [--dry-run] [--jobs N]` | Upload every (source, topic) with no verified object, proving each by downloading it back (`--verify get`, the default) or by comparing ETag and length (`--verify head`). Needs credentials. |
| `shelf fetch [--all \| CITEKEY] [--dry-run] [--force]` | Rebuild `pdfs/` from the remote, falling back to arXiv where provenance allows. No credentials needed. `--force` displaces a mirror whose digest does not match into `pdfs/.displaced/`. |
| `shelf url CITEKEY [--topic T] [--signed] [--expires DURATION]` | Print a source's object URL. `--signed` emits a presigned one — not a privacy control on a public-read object, just a link that stops working — with `--expires` as `Ns`, `Nm`, `Nh` or `Nd`, clamped to 7d. |
| `shelf manifest check [--require] [--require-remote]` | Validate `manifest/sources.yaml` against the topics on disk. `--require` also fails when the manifest or `topics/` is missing; `--require-remote` also fails on warnings, so every source must carry a verified object for every topic. This is the CI gate. |
| `shelf cleanup [--execute --yes] [--offline] [--include-unsourced --i-accept-two-copies] [--allow-repo DIR]` | Remove duplicate PDFs the shelf can prove are safe to delete. Prints the plan and changes nothing unless both `--execute` and `--yes` are given; every action is written to `manifest/cleanup-log.yaml` before and after it happens. |

## Adding sources

`shelf scan` → triage the results in `manifest/scan.yaml` → `shelf apply` to commit
them into `manifest/sources.yaml` and generate `text/` + `topics/<t>/refs/` entries
→ `shelf push` to mirror the PDFs and record their verified objects.
Never hand-edit `sources.yaml` except for metadata fixes, then run
`shelf manifest check`.

## Reading PDFs from Emacs

`tools/emacs/cfmm-refs.el` opens any shelf PDF straight from the public Hippius bucket
(no credentials): `(load "~/cfmm-refs/tools/emacs/cfmm-refs.el")`, then
`M-x cfmm-refs-open-pdf` (completion over citekeys; cached in `~/.cache/cfmm-refs/`,
prefix arg re-downloads), `M-x cfmm-refs-copy-url`, or `[[shelf:CITEKEY]]` links in org.
