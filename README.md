# wvs-docs

A topic-organized CFMM research shelf: papers, notes, and exercises on options,
volatility swaps, and the mathematics behind them, tracked as text with PDFs kept
local-only.

## Layout

```
wvs-docs/
├── README.md, CLAUDE.md
├── .gitignore
├── manifest/            # sources.yaml, scan.yaml (gitignored), cleanup-log.yaml, schema.json
├── topics/<topic>/
│   ├── INDEX.md         # generated by `shelf index`
│   ├── refs/<citekey>.md
│   ├── notes/
│   └── exercises/
├── text/<citekey>.md    # extracted text
├── agents/              # skills, commands, agent notes
├── docs/superpowers/{specs,plans}/
├── shelf/               # Haskell CLI (Phase 2+)
├── index/                # gitignored BM25 index cache
└── pdfs/                 # gitignored, local-only
```

## Reading

- **Tier 1** — read the extracted text directly under `text/<citekey>.md`.
- **Tier 2** — fetch the source PDF with `shelf fetch` (Phase 2; not yet implemented).

## Adding sources

`shelf scan` → triage the results in `manifest/scan.yaml` → `shelf apply` to commit
them into `manifest/sources.yaml` and generate `text/` + `topics/<t>/refs/` entries.
Never hand-edit `sources.yaml` except for metadata fixes, then run
`shelf manifest check`.
