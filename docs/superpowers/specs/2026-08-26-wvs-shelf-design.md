# wvs-docs → CFMM research shelf + DeepSeek plugin — design

Date: 2026-08-26. Status: approved in conversation; revised after two-reviewer
pass (Reality Checker + Backend Architect). Open decisions for the user are in §11.

## 1. Goal

Turn `JMSBPP/wvs-docs` into the single repository holding every CFMM-related
learning source (PDFs + notes + exercises) currently scattered across the local
machine, organised by topic, with PDFs stored off-git on Hippius, and — as a
later phase — expose it to DeepSeek Harness as a Haskell plugin agent built on
`haskell-deepseek-plugin-sdk`.

Non-goals: databases, embeddings/vector stores (until BM25 proves insufficient),
blind deletion of local files, ingesting non-CFMM corpora (post-keynesian,
bittensor, mamertomics, job-seeking, invoices).

## 3. Corpus facts (measured 2026-08-26)

## 5. Manifest (`manifest/sources.yaml`)

```yaml
schema_version: 1
sources:
  - citekey: milionis-amm-arbitrage-fees-2024
    sha256: "…64 hex…"
    bytes: 812345
    title: Automated Market Making and Arbitrage Profits in the Presence of Fees
    authors: [Milionis, Moallemi, Roughgarden]
    year: 2024                      # or "nd" when genuinely unknown
    provenance: {kind: arxiv, id: "2305.14604"}   # | doi | isbn | unsourced
    topics: [options, volatility-swaps]
    origin: [cfmm/cfmm-theory/milionis-amm_arbitrage_fees-2024.pdf]   # home-relative
    hippius:                        # absent until verified (Phase 2)
      key: pdfs/milionis-amm-arbitrage-fees-2024.pdf
      verified_sha256: "…"
      etag: "…"
      verified_at: 2026-09-01T10:00:00Z
```

Invariants (enforced by `Shelf.Manifest` types + `shelf manifest check`):

- citekey unique, regex `^[a-z0-9]+(-[a-z0-9]+)*-(\d{4}|nd)(-v\d+)?$`.
- sha256 unique. Same provenance with different sha256 (arXiv v1/v2,
  re-downloads) is flagged by `scan` for triage; policy: newest keeps the bare
  citekey, older ones get `-vN`.
- year: from arXiv id (`YYMM` prefix), else DOI/crossref is *not* queried (offline
  tool) — else `pdfinfo` CreationDate is only a *proposal* shown in triage; the
  human confirms or sets `nd`. Book PDFs routinely carry a wrong CreationDate.
- `topics` non-empty; each names an existing `topics/<t>/`.
- A row counts as **remote-backed** iff `hippius.verified_sha256 == sha256`.
  This is a value check on load, not a constructor-visibility promise — hand
  edits to the YAML cannot fake verification without also knowing the hash.
- `origin` is informational, home-prefix stripped.

## 6. Pipeline (`shelf` CLI)

1. `shelf scan [--root ~]` — walk, excluding `.git`, `.cache`, `.TinyTeX`,
   `site-packages`, `.venv`, `node_modules`, `actions-runner*/_work`, and any
   `lib/` whose parent has `foundry.toml`. sha256 every `*.pdf`, group by hash,
   read `pdfinfo` + first-page text, propose `citekey`, `topics`, `provenance`
   (arXiv regex `\d{4}\.\d{4,5}(v\d+)?` on filename/first page), `year`, and
   `include`. `include: true` only if under a D2 root **and** not matched by
   the junk heuristic (Producer contains `matplotlib`/`gnuplot`, or path
   contains `figures/`, `reports/`, `audits/`, or ≤2 pages with no Title).
   Writes `manifest/scan.yaml` via temp-file + rename. Re-scan merges by
   sha256 and **never overwrites** human-edited `include`/`citekey`/`topics`/`year`.
2. **Triage (human)** — edit `scan.yaml`. Nothing outside D2 roots is ever
   auto-included.
3. `shelf apply` — per `include: true` row, each step skip-if-present keyed by
   sha256: copy to `pdfs/<citekey>.pdf` (verify hash) → `extract` →
   scaffold `topics/<t>/refs/<citekey>.md` if absent (never overwrite a card)
   → **commit point:** upsert row into `sources.yaml` (atomic write, sorted) →
   drop the scan row. A crash before the commit point leaves only regenerable
   artifacts; re-running is idempotent.
4. `shelf extract [citekey|--all]` — runs `pdftotext -raw` for the committed
   body text and `-layout` only transiently for header detection. Header rule
   `^\d+(\.\d+)*\s+[A-Z][a-z]` → `## `; known to false-positive on equation
   numbers; golden tests include one known-bad fixture. Front-matter stamps
   `sha256`, `pdftotext_version`, `extractor_version`; any stamp mismatch
   re-extracts.
5. `shelf index` — regenerate `topics/*/INDEX.md`, `topics/README.md`, and the
   BM25 index in `index/` (rebuilt when manifest hash changes).
6. `shelf manifest check` — all §5 invariants; CI gate.
7. `shelf push [--all]` (Phase 2) — PUT with full-payload `x-amz-content-sha256`
   (no aws-chunked streaming), then GET and compare sha256 with retry/backoff
   (3 tries, 2 s/8 s/30 s — read-after-write consistency on Hippius is
   unverified); on success write the `hippius` record for that row immediately
   (atomic save per object, so `--all` resumes). `--verify=head` re-checks by
   ContentLength+ETag only.
8. `shelf fetch <citekey>|--all` — GET → verify → `pdfs/`; fallback
   `https://arxiv.org/pdf/<id>` when provenance is arxiv; error otherwise.
9. `shelf url <citekey>` — SigV4 presigned GET (default 24 h), path-style.
10. `shelf cleanup [--execute] [--allow-repo <path>]…` (Phase 2) — a local path
    is deleted iff **all** conjuncts hold, evaluated at execute time:
    1. path is a regular file (symlinks refused);
    2. **re-hashed now**, sha256 is in `sources.yaml` with `include` history true;
    3. that row is remote-backed (§5);
    4. `pdfs/<citekey>.pdf` exists in the shelf checkout with matching sha256;
    5. path is not inside *any* checkout whose `origin` remote is
       `JMSBPP/wvs-docs` (covers the submodule inside cfmm-theory);
    6. git status resolved against the **nearest enclosing repo**
       (`git -C dir rev-parse --show-toplevel`): ignored or untracked ⇒ plain
       delete; tracked ⇒ only if that repo is in `--allow-repo` **and** the
       index is clean for that path, then `git rm` and the repo is reported for
       a manual commit; tracked elsewhere ⇒ skip.
    Rows with `include: false` are never touched. Dry-run prints the full plan;
    `--execute` appends `{path, sha256, citekey, repo?, etag, deleted_at}` to
    `cleanup-log.yaml`.

Credentials (env only, never in git): `HIPPIUS_ACCESS_KEY_ID`,
`HIPPIUS_SECRET_ACCESS_KEY`, `HIPPIUS_BUCKET`, `HIPPIUS_REGION` (default
`decentralized`), `HIPPIUS_ENDPOINT` (default `https://s3.hippius.com`).

## 7. Haskell package `shelf/`

Stack resolver lts-24.56, fourmolu + hlint, CI on `ubuntu-latest`
(`stack build --test`, `shelf manifest check`, binary-in-git check allowing
only `shelf/test/fixtures/*.pdf`).

| Module | Responsibility | Key deps (all verified in lts-24.56) |
|---|---|---|
| `Shelf.Types` | `Citekey`, `Sha256`, `Topic`, `Provenance`, `Source`, `HippiusRecord` | `text`, `aeson` |
| `Shelf.Manifest` | YAML codec, invariants, atomic sorted save, `check` | `yaml 0.11`, `aeson` |
| `Shelf.Scan` | walk, hash, group, junk heuristic, proposals, merge | `directory`, `filepath`, `crypton 1.0`, `typed-process 0.2` |
| `Shelf.Extract` | typed wrapper over `pdftotext`/`pdfinfo`, header split, stamps | `typed-process` |
| `Shelf.Index` | BM25 (k1=1.2, b=0.75; lowercase, ASCII-fold, no stemmer; title tokens weighted ×3), persisted inverted index | `containers`, `binary` |
| `Shelf.Remote.SigV4` | canonical request, signing key, presign — ~150 lines | `crypton`, `memory`, `time` |
| `Shelf.Remote` | PUT/GET/HEAD against Hippius, verify, arXiv fallback | `http-client-tls 0.3`, `http-types` |
| `Shelf.Cleanup` | conjunct evaluation, `DryRun \| Execute`, log | `typed-process` (git) |

Executables: `shelf` (`optparse-applicative 0.18`) and, in Phase 3,
`dsh-plugin-wvs-shelf`.

Tests: `hedgehog 1.5` properties — manifest round-trip; cleanup never returns a
path failing any conjunct (each conjunct mocked independently); SigV4 test
vectors from the AWS spec. `tasty-golden` — `extract` on 3 fixture PDFs (incl.
one known-bad header case); BM25 fixture corpus where a title query lands in
top-3. Conformance replay of `corpus/shelf-*` frames for the plugin.

## 8. Plugin `dsh-plugin-wvs-shelf` (Phase 3)

**Hard external dependency:** `haskell-deepseek-plugin-sdk` (repo
`JMSBPP/haskell-deepseek-plugin-sdk-develop`, branch `main`, package name
`haskell-deepseek-plugin-sdk`, not on Hackage → `stack.yaml` git extra-dep) is
still at its Phase 1: `DeepSeek.Plugin` exports nothing and the echo example
exits non-zero. Phase 3 here cannot start until the SDK ships `runPlugin` with
Tool/Guard/Section records and output-schema validation (SDK phases 5–7).

Protocol version 1, NDJSON over stdio. `cwd` from `initialize` must contain
`manifest/sources.yaml`; otherwise the plugin replies `-32603` and exits —
PROTOCOL.md has no initialize-failure code besides `-32001`; raise this as a
protocol gap with the SDK.

Manifest contributions (field names checked against PROTOCOL.md §4/§6):

- tools (all with `output.schema`, `additionalProperties: false`):
  - `shelf_search {query, topic?, limit?=10}` → `{hits:[{citekey,title,topics,snippet,score}]}`; local; `concurrencySafe: true`.
  - `shelf_read {citekey, section?}` → `{citekey, section, text}`; `-32004` on unknown citekey/section.
  - `shelf_list {topic?}` → `{sources:[{citekey,title,year,topics}]}`.
  - `shelf_fetch_pdf {citekey}` → `{path, sha256}`; `timeoutMs: 60000`; `concurrencySafe: false`.
- guard `hippius-egress`: `match.tools: [shelf_fetch_pdf]`, `failPolicy: closed`, decides `ask` ("network + credentials").
- section `shelf:guidance` (order 150): cite as `[@citekey]`; prefer `shelf_read` with `section`; any exercise written carries an Economic Meaning section; never assert a paper's claim without a `shelf_read` in the same turn.
- no subagents in v1. BM25 index loaded once at `initialize` from `index/`.

## 9. Access model

Tier 1 (default): git clone → read `text/`, cards, indexes; no network.
Tier 2: `shelf fetch` / `shelf_fetch_pdf` → Hippius → `pdfs/`; arXiv fallback.
Tier 3: `shelf url` presigned link; if the Phase 2 hands-on check confirms
public-read buckets, `sources.yaml` gains a stable `url:` field.
The repo must remain fully usable with Hippius down.

## 10. Phases

- **Phase 1 (committed)**
  0. Preconditions: `cfmm/cfmm-theory` working tree clean (currently 64
     uncommitted changes incl. exercises the move touches — user commits or
     stashes first); decision O1 taken.
  1. Prune wvs-docs (`git rm` cruft, `.gitmodules` cleanup, `.gitignore`,
     `CLAUDE.md`, CI workflow).
  2. Restructure existing content into `topics/{options,volatility-swaps}/`.
  3. `shelf` package: `Types/Manifest/Scan/Extract/Index` + CLI
     `scan|apply|extract|index|manifest check`.
  4. `shelf scan` over `~` → triage → `apply`; commit manifest, `text/`, cards,
     indexes. PDFs stay local in gitignored `pdfs/`.
  5. cfmm-theory: add submodule, `git mv` notes/exercises into the submodule
     path, `git rm` its 22 tracked PDFs, one scoped commit.
- **Phase 2 (provisional)**: Hippius account/credits (user), `Shelf.Remote`
  + SigV4, `push/fetch/url`, hands-on checks (region, read-after-write,
  public-read, size limits), `cleanup` dry-run → review → `--execute`.
- **Phase 3 (provisional, gated on SDK)**: plugin, conformance corpus, harness wiring.
- **Phase 4 (open)**: embeddings if needed; "exercise-from-paper" subagent;
  arXiv-watch auto-ingest.

## 11. Open decisions for the user

- **O1 — wvs-docs history.** `.git` is 212 MB because 116 PDFs and `lib/` are
  in history; `git rm` at HEAD does not shrink clones (or the cfmm-theory
  submodule). Options: (a) **recommended** — one-time `git filter-repo
  --path-glob '*.pdf' --invert-paths` + drop `lib/` history, force-push `main`
  (26 commits, single-owner public repo, low blast radius); (b) keep history
  and document `git clone --filter=blob:none --recurse-submodules` for consumers.
- **O2 — Hippius account.** User creates the account (Google/GitHub sign-up)
  and funds credits before Phase 2; not needed for Phase 1.

## 12. Risks

- Hippius (Bittensor SN75) is young; durability, size limits, and consistency
  unverified → arXiv fallback + local mirror + never on the plugin hot path.
- `pdftotext` on math-heavy / two-column PDFs; mitigated by tier-2 PDF access
  and golden tests marking known-bad extractions.
- Cleanup is destructive by nature; mitigated by six conjuncts evaluated at
  execute time, dry-run default, log, and user-run `--execute`.
- Phase 3 is blocked on an SDK that is itself under construction.
